# 🌆 Tóquio - Descubra a Capital do Japão 

Este é um site informativo sobre Tóquio, criado com HTML, CSS e Bootstrap para oferecer uma experiência responsiva e estilizada. O site apresenta informações sobre a cidade, sua cultura, gastronomia, tradições e pontos turísticos imperdíveis.

## Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo do site.
- **CSS3**: Estilização personalizada para aprimorar o design.
- **Bootstrap**: Framework responsivo para facilitar a criação do layout e elementos interativos.
- **Slick Slider** (para carrosséis de imagens)

## Funcionalidades

- **Navbar Responsiva**: Um menu de navegação fixo e dinâmico.
- **Carrossel de Imagens**: Exibição de imagens em destaque sobre a cidade.
- **Seções Informativas**: Conteúdo sobre a cultura, tradições e pontos turísticos.
- **Sistema de Abas**: Organização de informações sobre restaurantes, templos e pontos turísticos.

## Estrutura do Site

1. **Sobre a Cidade**: Introdução sobre Tóquio, sua história e modernidade.
2. **Cultura**: Aspectos culturais como culinária, tradições e idioma.
3. **Lugares a Visitar**: Seção com sugestões de restaurantes, pontos turísticos e templos.
4. **Contato**: Formulário para agendamento de viagens.

## 🚀 Como Rodar o Projeto  
1. Faça o clone do repositório:  
   ```bash
   git clone https://github.com/Lucas-M-Bruno/toquio
   ```
2. Abra o arquivo `index.html` no navegador.
